### 1. 🔬 16 大进阶科研重器产业链
- 涵盖 **通风橱、高纯手套箱旋涂仪、X射线衍射仪(XRD)、紫外可见光谱仪、紫外测试台、QE Pro、Xeon超算、热蒸镀仪、X射线闪烁成像台、千级无尘超净间、飞秒瞬态吸收光谱系统、GPU智算集群、Titan球差校正透射电镜、上海光源/高能同步辐射专用线站** 等全套科研产业链；

### 2. 👥 真实研究生人事与月度劳务津贴系统
- **多元生源选拔**：发布校内保研招生简章或举办全国优秀大学生夏令营，面试遴选专长各异的保研生；
- **四维资质与境界突破**：实验手操 (Lab)、机理理论 (Theory)、数据洞察 (Analysis)、文献创新 (Insight) 四维成长路径，支持宗师突破考核；
- **月度劳务津贴结算**：月末统一从经费中结算发放研究生劳务补助（硕士生小白 500元/月、潜力新秀 1000元/月、骨干博士 2000元/月、天骄博士 4000元/月、创世神卡汪猛 8000元/月）。

## 🚀 本地运行与开发

无需安装任何构建工具，直接在本地启动任意静态服务器即可：

```bash
# 方式 1：Python 一键启动
python3 -m http.server 8090

# 方式 2：使用 Node.js http-server
npx http-server -p 8090

# 打开浏览器访问：
http://localhost:8090
```
